# Dota Hero Tower Defense (3D)

A 3D WebGL (Three.js + TypeScript) Tower Defense game inspired by classic Dota Hero TD, featuring 8 articulated 3D Dota Heroes, 40 hardcore waves across 4 dynamic seasons, Secret Shop items, and Roshan as the Wave 40 Final Boss.

## Features
- **8 Buyable & Upgradeable 3D Dota Heroes** (Level 1–4 *Aghanim's Scepter*): Sniper, Crystal Maiden, Sven, Venomancer, Lina, Earthshaker, Drow Ranger, and Zeus.
- **40-Wave Campaign & Difficulty Modes**: **Hard** and **Immortal** difficulties with Mini-Bosses every 5 waves and **Roshan — The Immortal Emperor** on Wave 40.
- **4 Dynamic 3D Seasons**: Spring, Summer, Autumn, and Winter (auto-progresses every 10 waves, or preview live via the HUD season button).
- **Dota Mechanics**: Physical (Armor), Magical (Magic Resist), and Pure damage types, Secret Shop items (*Desolator*, *Daedalus*, *Moon Shard*, *Octarine Core*), **Glyph of Fortification**, and **Sunstrike**.

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
